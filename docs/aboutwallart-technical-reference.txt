## gsc.js — Full Technical Details

**File:** `api/gsc.js`
**Added:** May 29, 2026
**Purpose:** GSC Report tool backend — connects to Google Search Console API AND Google Analytics 4 API

### Authentication:
- OAuth 2.0 with offline access (refresh token)
- No user login required — uses pre-authorized refresh token for mae@aboutwallart.com
- GSC property: `sc-domain:aboutwallart.com` (domain property — NOT URL prefix)
- GA4 property ID: `359661193`

### Google Cloud Project:
- **Project:** Money Page Optimizer
- **Project ID:** `money-page-optimizer`
- **APIs Enabled:** Google Search Console API, Google Analytics Data API

### OAuth App:
- **App Name:** About Wall Art GSO Tools
- **Redirect URI:** `https://tools.aboutwallart.com/api/gsc`
- **Test User:** mae@aboutwallart.com
- **Scopes:** `webmasters.readonly` + `analytics.readonly` (BOTH required in same token)

### Supported Actions (GET ?action=):
- `overview` — total clicks, impressions, CTR, avg position
- `monthly` — monthly breakdown for historical view
- `queries` — all queries with impressions
- `pages` — top pages by clicks (rowLimit: 500)
- `page-query` — page + query combined (rowLimit: 5000)
- `device` — device breakdown
- `blog-tracking` — performance of specific URLs (pass urls= param)
- `ga4-llm` — GA4 LLM traffic from AI referrers (?days=30/90/180)

### CRITICAL: URL Format
GSC returns URLs WITHOUT www: `https://aboutwallart.com/`
Shopify builds URLs WITH www: `https://www.aboutwallart.com/`
Always normalise before matching:
```javascript
url.replace('https://www.aboutwallart.com', 'https://aboutwallart.com')
```

### How to get a new Refresh Token:
IMPORTANT: Must include BOTH scopes in one token.
Use this URL:
```
https://accounts.google.com/o/oauth2/v2/auth?client_id=15466013888-deual871humreqd3uqhrve8chp3bci3s.apps.googleusercontent.com&redirect_uri=https://tools.aboutwallart.com/api/gsc&response_type=code&scope=https://www.googleapis.com/auth/webmasters.readonly%20https://www.googleapis.com/auth/analytics.readonly&access_type=offline&prompt=consent
```
1. Visit URL, sign in as mae@aboutwallart.com, click Allow
2. Copy `code` from redirect URL IMMEDIATELY (expires in ~60 seconds)
3. Go to hoppscotch.io — POST — `https://oauth2.googleapis.com/token`
4. Body (x-www-form-urlencoded):
   - code = [code from step 2]
   - client_id = 15466013888-deual871humreqd3uqhrve8chp3bci3s.apps.googleusercontent.com
   - client_secret = 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
   - redirect_uri = https://tools.aboutwallart.com/api/gsc

## shopify-files.js — Full Technical Details

**File:** `api/shopify-files.js`
**Last Updated:** May 29, 2026

### Actions:

#### GET ?action=get-blogs-by-month&month=YYYY-MM
- Used by GSC Report Blog Tracking
- Fetches articles by published_at date (NOT createdAt — blogs are scheduled months ahead)
- Returns: `{ success: true, month, articles: [{id, title, handle, publishedAt, url, blogTitle}] }`
- URL format: https://www.aboutwallart.com/blogs/{blogHandle}/{articleHandle}
- DO NOT include `seo` field in GraphQL query — doesn't exist on Article type

#### GET ?action=link-whisperer — Internal link data
#### POST action=update_alt_only — Update image alt text
#### POST action=replace_file — Full image replacement

### Known Issues:
- fileUpdate mutation is BROKEN in Shopify API
- Always use replace_file for image operations
- 3-second delay required between create and delete

## 1. High Level SEO Metrics
- Date range selector: 7/28/90/180 days
- 4 metric cards: Clicks, Impressions, CTR, Avg Position
- Line chart: daily clicks vs previous period
- Device donut chart
- Landing pages table + Queries table

## 2. Historical View (1 Year)
- Gauge charts with % change vs same month previous year
- Monthly bar charts: impressions and clicks
- Uses monthly GSC action

## 3. LLM Traffic
- GA4 Data API via ga4-llm action in gsc.js
- Sessions and page views per AI source
- Date range: 30/90/180 days
- AI sources tracked: chat.openai.com, chatgpt.com, perplexity.ai, claude.ai, gemini.google.com, copilot.microsoft.com, you.com, phind.com, poe.com
- **STATUS: v20 shows black screen — needs debugging (see Handover section)**

## 4. Blog Tracking
- Month selector (last 12 months) — selects blogs by Shopify published_at
- Fetches blogs from Shopify via get-blogs-by-month
- Fetches GSC data for ALL time (getDate(480) = 16 months) — not filtered by date
- URL matching: strips www to match GSC format
- Columns: Title (link), Url Clicks, % vs 30d, % vs 90d, Impressions, CTR, Avg Position
- % change only shown if previous period had 20+ clicks
- Row colours: green >5% growth, yellow ±5%, red >5% decline (based on 30d)
- Darker cell colour on whichever % column shows bigger change
- No download button

## 5. Blog Optimizations
- 3 tabs: Urgent (CTR <0.5%) | Improve (CTR 0.5%-1%) | Monitor (CTR >1%)
- Within each tab: sorted by lowest clicks first
- Filters: /blogs/ only, 100+ impressions, published >90 days ago, English only, no /es/ /fr/
- 90-day filter: fetches 16 months of Shopify data to build exclusion list
- Download CSV per tab
- Data: last 180 days

## 6. Content Optimizations
- **Fix CTR:** position 1-7, has clicks, CTR <2%, 100+ impressions, NO /blogs/, highest position first
- **Pages to Optimise:** position 8-15, CTR <2%, 100+ impressions, NO /blogs/, lowest position first
- **Low Ranking Opportunities:** real English queries, no matching content in registry, 10+ impressions, sorted by impressions
- All 3 tables: search, row count, Download CSV
- Cross-references /api/blogs?action=get-published-keywords

# TROUBLESHOOTING

## GSC API fails
- Check GSC_CLIENT_ID, GSC_CLIENT_SECRET, GSC_REFRESH_TOKEN in Vercel
- Refresh token must include BOTH scopes
- Follow "How to get a new Refresh Token" steps above

## GA4 LLM Traffic fails / black screen
- Check GA4_PROPERTY_ID = 359661193 in Vercel
- Check GSC_REFRESH_TOKEN includes analytics.readonly scope
- GA4 Data API must be enabled in money-page-optimizer Google Cloud project
- Open browser console on LLM Traffic tab — check for JS errors
- Call API directly: https://tools.aboutwallart.com/api/gsc?action=ga4-llm&days=90
- Check Vercel logs for specific error

## Blog Tracking shows 0 data
- URL mismatch — strip www before matching (already in v15+)
- Check Shopify get-blogs-by-month returns articles

## Blog Optimizations slow
- Fetches 16 months of Shopify data (16 API calls) — expected, takes a few seconds

## Content Optimizations shows blogs
- Should not happen in v19+ — /blogs/ URLs filtered out
- Check filter: !p.page.includes('/blogs/')

## CORS Errors
- Verify CORS headers in API file
- Verify vercel.json CORS config
- Redeploy after changes

## Vercel function limit
- 11/12 (reddit.js and openai.js unused)
- Max 1 more API file before removing unused ones
