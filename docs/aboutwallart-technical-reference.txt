## gsc.js — Full Technical Details

**File:** `api/gsc.js`
**Last Updated:** May 30, 2026
**Purpose:** Easy SEO Report backend — GSC + GA4 data

### Authentication:
- OAuth 2.0 with offline access (refresh token)
- No user login required — uses pre-authorized refresh token for mae@aboutwallart.com
- GSC property: `sc-domain:aboutwallart.com` (domain property — NOT URL prefix)
- GA4 property ID: `359661193`

### Google Cloud Project:
- **Project:** Money Page Optimizer
- **Project ID:** `money-page-optimizer`
- **APIs Enabled:** Google Search Console API, Google Analytics Data API

### OAuth App:
- **App Name:** About Wall Art GSO Tools
- **Redirect URI:** `https://tools.aboutwallart.com/api/gsc`
- **Test User:** mae@aboutwallart.com
- **Scopes:** `webmasters.readonly` + `analytics.readonly` (BOTH required in same token)

### Supported Actions (GET ?action=):
- `overview` — total clicks, impressions, CTR, avg position
- `monthly` — monthly breakdown for historical view
- `queries` — all queries with impressions (rowLimit: 1000)
- `pages` — top pages by clicks (rowLimit: 500)
- `page-query` — page + query combined (rowLimit: 5000)
- `device` — device breakdown
- `blog-tracking` — performance of specific URLs (pass urls= param)
- `keyword-monthly` — monthly impressions+clicks for exact keyword (pass keyword= param) — used by Keyword Tracker growth chart
- `ga4-traffic-breakdown` — GA4 sessions by page path and month (rowLimit: 5000) — used by Suspicious Traffic stacked chart
- `ga4-suspicious` — GA4 sessions with bounce rate by month — used by Suspicious Traffic gauge
- `ga4-llm` — GA4 LLM/AI referral traffic (?days=30/90/180)

### CRITICAL: URL Format
GSC returns URLs WITHOUT www: `https://aboutwallart.com/`
Shopify builds URLs WITH www: `https://www.aboutwallart.com/`
Always normalise before matching:
```javascript
url.replace('https://www.aboutwallart.com', 'https://aboutwallart.com')
```

Use this URL:

## blogs.js — Full Technical Details

**File:** `api/blogs.js`
**Last Updated:** May 30, 2026
**Purpose:** Blog Manager tool backend + all Easy SEO Report data storage actions

### GET Actions (?action=):

#### get-published-keywords
- Returns all Published Blog + To_Write_Blog keywords from registry CSV
- Returns: `{ success: true, publishedBlogs: [{keyword, url}] }`

#### get-registry
- Returns full keyword-locker-registry.csv as structured array
- Returns: `{ success: true, registry: [{keyword, url, locked, status, action}] }`
- Only rows with locked=LOCKED + status=DONE + action=TO_OPTIMIZE or OPTIMIZED count as truly locked

#### get-revenue-by-month
- Fetches last 13 months of revenue via Shopify REST Orders API
- Returns: `{ success: true, revenue: { YYYYMM: amount } }`
- NOTE: Currently returning 0 values — Shopify read_orders scope may need verifying
- Skips voided/refunded orders

#### get-susp-events
- Returns saved suspicious traffic chart events from data/suspicious-events.json
- Returns: `{ success: true, events: [{label, date}] }`

#### get-optimisations
- Returns keyword optimisation dates from data/keyword-optimisations.json
- Returns: `{ success: true, optimisations: { tabId: 'YYYY-MM-DD' } }`

#### get-tracked-keywords
- Returns tracked keyword list from data/tracked-keywords.json
- Returns: `{ success: true, keywords: ['kw1', 'kw2', ...] }`

#### get-keyword-tabs
- Returns keyword tracker tabs from data/keyword-tracker.json
- Returns: `{ success: true, tabs: [{id, label, keyword}] }`

#### GET (no action) — Blog ideas pipeline (for Blog Manager tool)

### POST Actions (req.body.action):

#### lock-keyword
- Saves keyword+URL to keyword-locker-registry.csv on GitHub
- Format: LOCKED, DONE, TO_OPTIMIZE, User Resolved
- Body: `{ action: 'lock-keyword', keyword, url }`

#### save-susp-events
- Saves suspicious traffic chart events to data/suspicious-events.json
- Body: `{ action: 'save-susp-events', events: [{label, date}] }`

#### save-optimisations
- Saves keyword optimisation dates to data/keyword-optimisations.json
- Body: `{ action: 'save-optimisations', optimisations: { tabId: 'YYYY-MM-DD' } }`

#### save-tracked-keywords
- Saves tracked keywords list to data/tracked-keywords.json
- Body: `{ action: 'save-tracked-keywords', keywords: [...] }`

#### save-keyword-tabs
- Saves keyword tracker tabs to data/keyword-tracker.json
- Body: `{ action: 'save-keyword-tabs', tabs: [{id, label, keyword}] }`

#### POST (no action) — Mark blog as To Write (Blog Manager)
#### PATCH — Mark as Keyword Change (Blog Manager)
#### DELETE — Undo (Blog Manager)

### Google Sheets Integration:
- Webhook URL in Vercel env var: SHEETS_WEBHOOK_URL
- Non-blocking
- Google Sheet ID: 1W9AYH2Zcw-v2U6S47a3w5bs5rEBf6K30adDgNkaZ38k

## 1. High Level SEO Metrics
- Date range selector: 7/28/90/180 days
- 4 metric cards: Clicks, Impressions, CTR, Avg Position
- Line chart: daily clicks vs previous period
- Device donut chart
- Landing pages table + Queries table

## 2. Historical View (1 Year)
- Gauge charts with % change vs same month previous year
- Monthly Clicks bar chart with Net Sales overlay (dual Y axis — impressions left, revenue right)
- Monthly Impressions bar chart
- NOTE: Net Sales currently showing 0 — Shopify revenue API needs debugging

## 3. 🚨 Suspicious Traffic
- GA4 bounce rate data as proxy for suspicious/bot traffic
- Gauge: current month suspicious % vs same month last year
- Stacked bar chart: two bars per month
  - Left bar: total sessions (violet)
  - Right bar: stacked breakdown — 🔴 Suspicious | 🟣 Collections | 🟢 Blogs | 🟠 Products | 🔵 Pages | 🟡 Ad Intent
- Ad Intent URL tracked: `/collections/art-prints-for-wall`
- 📌 Chart Events panel: add named events with dates (e.g. "Ad Intent budget added")
  - Saved to data/suspicious-events.json on GitHub
  - Shows as vertical coloured dashed lines on chart with labels
- Summary table: monthly breakdown with risk levels (Low/Medium/High)

## 4. 🤖 AI Traffic
- GA4 Data API via ga4-llm action
- Per-source cards (ChatGPT, Perplexity, Claude, Gemini, Copilot, etc.)
- Each card: gauge (outer=views, inner=sessions) + bar chart (6 months fixed)
- Top overview: donut chart (sessions by source) + 12-month line chart
- Date range: 30/90/180 days selector
- Duplicate sources merged (chatgpt.com + chat.openai.com = one card)

## 5. 🔥 Quick Wins
- Pages ranking position 1–20 with 100+ impressions
- Page type sub-tabs: Collections | Blogs | Products | Pages
- All / Selected sub-tabs with + Select and ↩ Undo buttons
- Column sort: click any header for priority-based sorting (1↑ badges)
- Registry column: 🔒 Locked | 🟡 Keyword taken | 🔴 URL taken
- Save to Registry: locks keyword+URL with LOCKED/DONE/TO_OPTIMIZE/User Resolved
- Search bar + data loads independently

## 6. ⚠️ Danger Pages
- Pages where clicks dropped 20%+ vs previous 90 days (min 10 clicks previous period)
- Same structure as Quick Wins: page type sub-tabs, All/Selected, sort, registry
- Keyword column showing top ranking keyword per URL
- Save to Registry: same rules as Quick Wins
- Loads independently (does not depend on Quick Wins loading first)

## 7. Keyword Tracker
- Named tabs saved to GitHub (keyword-tracker.json)
- Each tab tracks a keyword and shows:
  - 5 metric cards (Queries Found, Clicks, Impressions, CTR, Avg Position)
  - 📅 Optimisation date marker: date input, Save Date button, green badge, Clear button
  - Growth chart (12 months): Impressions + Clicks on single Y axis
  - Vertical green dashed line on chart at optimisation month
  - Query table: all queries containing the keyword with Ranking URL column (clickable)
- Tabs are renameable and deletable
- Optimisation dates saved to data/keyword-optimisations.json

## 8. Keyword Rankings
- All GSC queries with metrics for last 90 days
- Filters: Search, Position range, Difficulty, Min Impressions, Row limit
- Column sort: click any header, priority badge system (1↑, 2↓ etc), ✕ to remove
- Difficulty: Easy/Medium/Hard calculated from position + impressions + CTR
- All tab: + Select button moves keyword to Selected tab
- Selected tab: Ranking URL, Registry (🔒/🟡/🔴), ↩ Undo, Save to Registry
- Trend column in Selected tab: ▲ green / ▼ red / ▶ amber vs previous 90 days
- Saved selections in data/tracked-keywords.json

## 9. Blog Optimizations
- Blog posts only (/blogs/ URLs)
- Excludes: CDN, /es/, /fr/, ?param URLs, Quick Wins URLs, Danger Pages URLs
- 3 tabs: 🔴 Urgent (CTR <0.5%) | 🟡 Improve (0.5%-1%) | ⚪ Monitor (>1%)
- Sorted by lowest clicks first within each tab
- Filters: 100+ impressions, published >90 days ago, English only
- Download CSV per tab

## 10. Content Optimizations
- Non-blog pages only
- Excludes: CDN, /es/, /fr/, ?param URLs, Quick Wins URLs, Danger Pages URLs
- Fix CTR: position 1-7, has clicks, CTR <2%, 100+ impressions
- Pages to Optimise: position 8-15, CTR <2%, 100+ impressions
- Low Ranking Opportunities: queries with no matching registry content, 10+ impressions
- All tables: search, row count, Download CSV
