# IMAGE OPTIMIZER TOOL

## Overview
**File:** `image-optimizer-v2.10.html`
**API:** `api/shopify-files.js`
**Status:** Production (May 26, 2026)
**Purpose:** Automated image optimization and alt text generation for Shopify stores

## Features

### Core Functionality:
1. **Page Scanning**
   - Scans any URL on aboutwallart.com
   - Extracts all images (product, blog, collection pages)
   - Analyzes file size, format, dimensions, alt text

2. **Image Optimization**
   - Converts images to WebP format
   - Compresses to ~85% quality
   - Target: <500KB per image
   - Client-side optimization (no server upload)

3. **Alt Text Generation**
   - Uses Claude Vision API (Anthropic)
   - Generates descriptive, SEO-friendly alt text
   - Context-aware (UI elements vs product images)
   - Keyword-optimized descriptions

4. **Shopify Integration**
   - Direct upload to Shopify Files via Admin API
   - Replaces existing files while preserving URLs
   - Updates alt text in Shopify metadata
   - Handles file conflicts and versioning

### Color-Coded Issue Detection:
- 🟦 **Blue:** Alt text missing only (AUTO - push to Shopify)
- 🟨 **Yellow:** Image too large only (AUTO - optimize and push)
- 🟧 **Orange:** Alt text missing (MANUAL - theme section)
- 🟪 **Purple:** Image too large (MANUAL - theme section)
- 🔴 **Red:** Both issues present (manual fix required)
- 🟩 **Green:** No issues / resolved

### Tab System:
- **To Fix:** Shows all images needing attention (sorted by color)
- **Resolved:** Shows fixed images (with undo functionality)

## Technical Architecture

### Frontend (image-optimizer-v2.10.html):
- Pure HTML + vanilla JavaScript
- No external dependencies except:
  - Claude Vision API (via fetch)
  - Shopify Admin API (via fetch to proxy)
- Implements:
  - Image scanning via HTML fetch + DOM parsing
  - Canvas-based image optimization
  - WebP conversion with quality control
  - Base64 encoding for API transmission

### Backend API (api/shopify-files.js):
- **Endpoint:** `https://seo-tools-lake.vercel.app/api/shopify-files`
- **Method:** POST
- **Authentication:** Shopify access token (environment variable)
- **API Version:** 2025-01

### Supported Actions:

#### 1. `replace_file`
**Purpose:** Replace existing image file in Shopify
**Flow:**
1. Find file by filename using GraphQL query
2. Create staged upload target
3. Build multipart form data manually (no FormData dependency)
4. Upload optimized image to staged URL
5. Create new file with alt text via `fileCreate`
6. Delete old file after 3-second delay

**GraphQL Mutations Used:**
- `files(query: "filename:...")` — Find file
- `stagedUploadsCreate` — Get upload target
- `fileCreate` — Create new file
- `fileDelete` — Remove old file

#### 2. `update_alt_only` (DEPRECATED - NOT WORKING)
**Status:** Known Shopify API bug - silently fails
**Issue:** `fileUpdate` mutation returns success but doesn't persist alt text
**Replaced by:** `replace_file` for all operations

## Shopify API Integration

### Required Scopes:
```
write_content
read_content
write_files
read_files
write_product_listings
read_product_listings
write_products
read_products
```

### Environment Variables (Vercel):
```
SHOPIFY_STORE_DOMAIN=aboutwallart.myshopify.com
SHOPIFY_ACCESS_TOKEN=[admin API token]
```

### API Endpoint Configuration:
- **URL:** `https://{SHOPIFY_STORE_DOMAIN}/admin/api/2025-01/graphql.json`
- **Headers:**
  - `Content-Type: application/json`
  - `X-Shopify-Access-Token: {SHOPIFY_ACCESS_TOKEN}`

### Key GraphQL Operations:

#### Find File by Filename:
```graphql
query {
  files(first: 5, query: "filename:image.jpg") {
    edges {
      node {
        ... on MediaImage {
          id
          alt
        }
      }
    }
  }
}
```

#### Create Staged Upload:
```graphql
mutation {
  stagedUploadsCreate(input: [{
    resource: IMAGE,
    filename: "image.webp",
    mimeType: "image/webp",
    httpMethod: POST
  }]) {
    stagedTargets {
      url
      resourceUrl
      parameters { name value }
    }
  }
}
```

#### Create File with Alt Text:
```graphql
mutation {
  fileCreate(files: [{
    originalSource: "[staged URL]",
    contentType: IMAGE,
    alt: "Descriptive alt text here"
  }]) {
    files { id alt }
    userErrors { field message }
  }
}
```

#### Delete File:
```graphql
mutation {
  fileDelete(fileIds: ["gid://shopify/MediaImage/123"]) {
    deletedFileIds
    userErrors { field message }
  }
}
```

### Known Limitations:

1. **Theme Section Images:**
   - Alt text stored in `settings_data.json`, not Files API
   - Cannot update via API
   - Must be updated manually in theme editor
   - Tool marks these as MANUAL (orange/purple)

2. **File Matching:**
   - Filename must match exactly (case-sensitive)
   - Query parameter `?v=timestamp` stripped before matching
   - CDN URLs cleaned before binary fetch

3. **Async Processing:**
   - 3-second delay required between create and delete
   - Shopify processes file creation asynchronously
   - Immediate delete can fail if file not yet ready

## Usage Workflow

### Typical User Flow:
1. Open Image Optimizer tool
2. Enter page URL (e.g., `/collections/black-and-white`)
3. Click "Scan Images"
4. Review color-coded results in "To Fix" tab
5. For each image:
   - Click "Generate Alt Text" (uses Claude Vision)
   - Review/edit alt text
   - Click "Optimize" if needed (converts to WebP)
   - Click "Push to Shopify" (individual purple button)
   - Click "Mark as Done"
6. Image moves to "Resolved" tab (green) with undo button
7. Continue until "To Fix" tab is empty

### Manual Workflow (Orange/Purple Cards):
1. Orange (theme section alt text):
   - Copy generated alt text
   - Go to Shopify admin → Themes → Customize
   - Find image in theme editor
   - Paste alt text
   - Check "Mark as manually fixed" checkbox
   - Card moves to Resolved

2. Purple (theme section optimization):
   - Click "Optimize" to download WebP
   - Manually upload to Shopify Files
   - Update theme to use new file
   - Check "Mark as manually fixed" checkbox
   - Card moves to Resolved

# TROUBLESHOOTING

## Common Issues

### Image Optimizer: "File not found in Shopify"
**Symptom:** Push to Shopify fails with "File not found"

**Causes:**
1. File was previously modified and filename changed
2. Filename doesn't match Shopify exactly
3. File exists in theme but not in Files

**Solution:**
1. Check Shopify Admin → Content → Files
2. Search for the filename
3. If missing: Download → Manually upload
4. If exists but different name: Note actual filename in tool

### Image Optimizer: Alt text not showing on page
**Symptom:** Alt text updates in Shopify Files but not on website

**Cause:** Image is in theme section, not managed by Files API

**Solution:**
1. Shopify Admin → Online Store → Themes → Customize
2. Find the image in theme editor
3. Manually update alt text field
4. Save theme

### Shopify API: Rate Limiting
**Symptom:** 429 Too Many Requests error

**Solution:**
- Shopify Admin API: 2 requests/second
- Wait and retry
- Tool includes 3-second delays between operations

### CORS Errors
**Symptom:** "No 'Access-Control-Allow-Origin' header"

**Solution:**
- Verify `vercel.json` has correct CORS headers
- Redeploy after any changes to `vercel.json`
- Clear browser cache

# SECURITY NOTES

## API Key Protection

**CRITICAL:** API keys are stored in Vercel environment variables, NEVER in code.

### What's Protected:
- All keys in Vercel are encrypted
- Keys never exposed in frontend code
- Keys never committed to GitHub
- API endpoints act as proxy, hiding keys from users

### Access Control:
- Only Vercel serverless functions can access environment variables
- Frontend never sees actual API keys
- Users can't extract keys from browser console

### Shopify Token Security:
- Admin API token has scoped permissions
- Token stored as environment variable
- Never transmitted to client
- All Shopify calls proxied through `api/shopify-files.js`
