Auto-Link Webhooks

Register webhooks with Shopify so auto-link rules are applied automatically whenever a new product or collection is created. Only needs to be done once. Your current words-to-ignore list and data type settings are saved to GitHub so the server can use them.

Clean Product Link Records

Removes any products from the tracking file that are not from the About Wall Art vendor. Run this once to clean up records added before this tool existed. Make sure your Shopify data is synced before clicking.

Clean Up Duplicate Phrases

Scans all pages, blog posts, collections and trend pages for duplicate inbound link phrases saved before the deduplication fix. Removes extra copies and merges multiple collection links into one sentence. Make sure your Shopify data is synced before clicking.

Clear Stored Data

Clears all cached Shopify data and forces a full fresh sync next time you load the tool. Use this if data looks out of date.
