🔴 Review Snippets Invalid Critical
194 product pages — no star ratings showing in Google search results
🔴 Not fixed
Your product pages output two Product schemas — one from the Minimog theme, one from Judge.me. Google sees a conflict and rejects both, so no star ratings appear in search results. The fix is to remove the theme's schema and leave only Judge.me's (which has the real review data).
⭐ Star ratings in Google search results increase click-through rate by 15–30%. Every product page is missing this right now.
📋 Step-by-step fix guide
1
Duplicate your live theme first
Never edit the live theme directly. Go to Shopify Admin → Online Store → Themes → three dots next to your live theme → Duplicate.
Open Shopify Themes →
2
Open the theme code editor
Three dots next to your live theme → Edit code.
3
Open snippets/product-data.liquid
In the left file tree, find the Snippets folder and click product-data.liquid.
4
Find and delete this block
Use Ctrl+F (or Cmd+F) to search for "@type": "Product" — find the one inside a <script type="application/ld+json"> tag and delete the entire block from the opening <script> to the closing </script>.
← DELETE THIS ENTIRE BLOCK:
<script type="application/ld+json">
  {
    "@context": "http://schema.org/",
    "@type": "Product",
    "name": {{ product.title | json }},
    "url": {{ request.origin | append: product.url | json }},
    ... (all the way to the closing brace)
  }
</script>
⚠️ Only remove the Product schema script block. Leave everything else in the file — especially the JavaScript product data and any 3D model JSON.
5
Save the file
Click Save in the top right of the code editor.
6
Test with Google's Rich Results Test
Paste any product URL and confirm only one Product schema appears with aggregateRating from Judge.me.
Open Rich Results Test →

⚙️ Settings

Registry maintenance tools. Run these when needed — they do not affect your daily SEO work.

🔧 Repair Registry

Fixes all existing rows in the registry CSV — pads any row with fewer than 12 columns, and overwrites the intent on every row based on the page URL (N/A = UNKNOWN, /collections/ or /products/ = COMMERCIAL, /blogs/ = INFORMATIONAL, /pages/ = NAVIGATIONAL). This corrects all historically wrong intents. Run once after deploying v1.6.

🔗 Fix URL Format

Some registry entries were saved with "www" in the URL. This button finds all of them and removes the "www" so every URL is in the same format.

🔍 Duplicate Keyword Finder

Finds keywords that are locked to more than one URL with the same intent — this confuses Google about which page to rank. Review each group and delete the duplicate row you don't want to keep.
