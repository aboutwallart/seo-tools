5 · Publish to Etsy

Two ways: create a brand-new draft from the prices above, or apply this listing to a template — a draft whose SKU contains "template" — so it keeps that template's international pricing (prices and variations are left untouched).

Sent items

Drafts you've sent. Saved in GitHub (they show on any computer). Preview or delete if you discard one.

Edit Descriptions

Find/replace text in your Etsy descriptions, or rewrite them with AI by giving an instruction. Preview first, then Apply — every original is backed up. Edits LIVE Etsy listings.

⚠ AI rewrite uses Claude tokens (costs money) — one call per description. Best on SKUs or one section, not on "All", unless you really mean it.

⚠ "All" edits hundreds of live listings — always Scan and review the preview before Apply.

Replace images

Match each Etsy listing to its Shopify product by SKU, swap its photos (and video) for Shopify's, drop images you don't need, add new ones, reorder, and push to Etsy. The common set below is added to the end of every listing.

Common set

These images go at the end of every listing, in this order. Upload once — saved to GitHub (shows on every computer). Drag to reorder, × to remove.

Listings by Etsy section

Pick a section, then edit each listing: drop images you don't want, add Shopify photos or upload new ones, reorder, pick the video, and Save. The common set is added at the end automatically. Max 20 images. Editing changes a LIVE Etsy listing — its old images are backed up first.

Compliance photo

Adds one real photo (common image #2) to every active + draft Etsy listing, to meet Etsy's rule that at least one photo isn't AI or a mockup. It skips the listings you already finished in Replace images (so nothing goes in twice). If a listing already has 20 images, the last one is removed to make room — its URL is backed up first. Runs in batches: press Start once and it keeps going on its own; you can Stop and resume any time (it never repeats a listing). Keep this tab open while it runs.
